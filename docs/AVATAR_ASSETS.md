# Referência de assets para os animais do NEXO

O app usa os PNGs de `public/avatar/Previews` para mostrar os pets no editor e na arena. Os modelos 3D GLB/OBJ/FBX continuam disponíveis em `public/avatar/Models` para uma etapa futura de visualização 3D. O componente lê os pets de `lib/animals/catalog.ts`.

O pacote presente é **Cube Pets**, criado/distribuído por Kenney. A licença incluída em `public/avatar/License.txt` é **CC0** e permite uso pessoal, educacional e comercial. Atribuição não é exigida, mas registrar Kenney nos créditos é uma boa prática.

Os previews e os modelos foram mantidos no formato original. O navegador usa os PNGs diretamente; isso evita instalar um renderizador 3D e deixa a tela de avatar leve. A origem do pacote está em https://kenney.nl/.
